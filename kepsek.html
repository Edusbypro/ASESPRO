Panduan Ketik Aksara, Arab & Matematika
1. Aksara Jawa (Hanacaraka)

Cara paling aman agar Aksara Jawa tidak rusak di HP siswa adalah dengan menjadikannya gambar.

  1. Klik tombol Buka Web di bawah ini.
  2. Ketik abjad latin, web otomatis mengubahnya ke Aksara Jawa.
  3. Gunakan pemotong layar (Windows + Shift + S), blok teks Jawanya.
  4. Di Studio Soal, tekan Ctrl + V (Paste).
Web Aksara Jawa
2. Huruf Arab / Hijaiyah

Ketik huruf latin biasa, dan akan otomatis berubah menjadi huruf Arab bersambung.

  1. Klik tombol Keyboard Arab di bawah.
  2. Ketik abjad latin (misal: bismillah), blok lalu Copy (Salin).
  3. Di Studio Soal, klik ikon RTL (Panah Kanan ke Kiri) di toolbar editor.
  4. Tekan Ctrl + V (Paste).
Keyboard Arab (Yamli)
3. Matematika, Grafik & Shape

Untuk menjamin rumus/grafik tidak berantakan di HP siswa, Wajib dijadikan Gambar (Screenshot).

  1. Buka MS Word (Rumus/Shape) atau Excel (Grafik/Chart).
  2. Buat materi Anda di sana dengan rapi.
  3. Tekan tombol Windows + Shift + S di keyboard, lalu blok rumus/grafiknya.
  4. Di Studio Soal, tekan Ctrl + V (Paste).
